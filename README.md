# Futuristic-3D-Printed-PCB
This is a 3D printed PCB designed in Autodesk Fusion and KiCad. It uses 12 LEDs arranged in a firework pattern and connects to an Arduino Uno, allowing the LEDs to be programmed with different patterns. It is innovative because 3D printed PCBs are still uncommon and provide a cost-effective way to create custom electronics without manufacturing a traditional PCB. The concept also has many possibilities beyond this project, such as custom LED displays, interactive designs, sensors, and other programmable electronics. By combining 3D printing with electronics, the design can be easily customized and adapted for many different projects.
